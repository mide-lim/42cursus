## Sobre a 42

A 42 é uma rede de formação em tecnologia baseada em projetos e aprendizado entre pares. Em vez de aulas tradicionais, os estudantes pesquisam, desenvolvem, testam e defendem suas soluções, aprendendo também com as avaliações e a colaboração com outros estudantes.

Este repositório reúne uma visão geral da minha trajetória na **42 Rio** e conecta os projetos que possuem repositórios públicos. Cada projeto tem desafios próprios e representa uma etapa do meu desenvolvimento como profissional de tecnologia.

## Competências

| Área | Conceitos e ferramentas trabalhados |
| --- | --- |
| Fundamentos de programação | C, memória, ponteiros, estruturas de dados e algoritmos |
| Sistemas e Unix | Shell, processos, sinais, arquivos e ambiente Linux |
| Concorrência | Threads, mutexes e sincronização |
| Programação orientada a objetos | C++ e seus fundamentos |
| Gráficos | Representação gráfica e exploração de ambientes 2D e 3D |
| Redes e infraestrutura | Redes, serviços e contêineres |
| Trabalho colaborativo | Pesquisa, revisão entre pares, comunicação e resolução de problemas |
